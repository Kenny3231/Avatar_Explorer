# 🎨 Avatar Explorer

An interactive, fast web app for searching, filtering and downloading Bitmoji poses (Solo and Duo) in high definition.

## ✨ Features

* **Advanced Search:** Smart pose filtering that ignores accents and case.
* **Interface & Catalog in 14 languages:** French, English, Spanish, French (Canada), German, Japanese, Korean, Italian, Portuguese, Chinese, Turkish, Polish, Romanian, Greek. The language selector translates **the whole interface** (text, buttons, help center), not just the pose catalog.
* **Dynamic Categories:** Auto-completed dropdown listing every existing category.
* **Solo & Duo Modes:** Preview with one or two characters at once.
* **Bulk Export:** Generate a `.zip` file from the web interface (limited by the browser).
* **🤖 Automatic Export (Recommended):** Generate a Bash script for direct, unlimited integration into Home Assistant.

## 🤖 Home Assistant Integration (Automatic)

This feature automatically downloads all poses and their metadata files directly into your Home Assistant storage, with no manual steps.

### Quick command
Run this command in your Home Assistant terminal (the "Terminal & SSH" add-on):

```bash
curl -sL "https://avatar-explorer.pages.dev/api/export?id1=YOUR_ID&name1=Kenny&mode=solo&dir=bitmojis" | bash
```

### API parameters
| Parameter | Description | Possible values |
| :--- | :--- | :--- |
| `id1` | **(Required)** Main Bitmoji ID | E.g.: `103719...` |
| `id2` | Friend's Bitmoji ID (required for duo) | E.g.: `284610...` |
| `name1` | Folder/prefix for user 1 | Default: `Utilisateur1` |
| `name2` | Folder/prefix for user 2 | Default: `Utilisateur2` |
| `mode` | Type of poses to fetch | `solo` or `duo` |
| `scale` | Image quality (1x, 2x, 4x) | `1`, `2`, `4` |
| `dir` | Folder under `/config/www/` (sub-folders allowed with `/`) | Default: `bitmojis`, e.g. `media/bitmojis` |
| `lang` | Pose catalog language | Default: `fr`. See [available languages](#-available-languages) |

> **Prerequisite:** Before running the command, make sure you've manually created your destination folders under `/config/www/` (e.g. `/config/www/bitmojis/Kenny/`). The script requires those folders to already exist so it can drop the `.png` and `.json` files into them.

## 📡 Metadata API (`aide.json`)

The `aide.json` file is served statically at the site root and exposes, among other things, the date of the last catalog import. Useful for a third-party app (e.g. Avatar Explorer HA) to know whether it should trigger a new import.

### Endpoint
```
GET https://avatar-explorer.pages.dev/aide.json
```

### Response
```json
{
  "date_maj": "19 juillet 2026",
  "last_updated_iso": "2026-07-19T10:10:28.730Z",
  "stats": {
    "fr": { "solo": 1261, "duo": 614 },
    "en": { "solo": 1975, "duo": 1050 },
    "es": { "solo": 1278, "duo": 607 },
    "...": { "solo": "...", "duo": "..." }
  },
  "guide": {
    "fr": "Bienvenue dans la Forge Bitmoji ! ...",
    "en": "Welcome to the Bitmoji Forge! ...",
    "es": "¡Bienvenido a la Forja Bitmoji! ...",
    "...": "..."
  }
}
```

| Field | Type | Description |
| :--- | :--- | :--- |
| `date_maj` | `string` | Date of the last import, formatted in French (display only, do not parse). |
| `last_updated_iso` | `string` (ISO 8601) | Date of the last import, to be used for any programmatic comparison. |
| `stats.<lang>` | `{ solo: number, duo: number }` | Number of poses available for language `<lang>` (one of the 14 codes above), per mode. |
| `guide.<lang>` | `string` (Markdown) | Text shown in the app's help center, translated for language `<lang>`. |

### Usage example
```js
const { last_updated_iso } = await fetch('https://avatar-explorer.pages.dev/aide.json').then(r => r.json());
const remoteDate = new Date(last_updated_iso);

if (remoteDate > localLastImportDate) {
  // trigger a new import
}
```

> [!NOTE]
> `aide.json` is regenerated automatically every Monday (GitHub Actions cron) and on every manual trigger of the `update_data.yml` workflow. `last_updated_iso` only changes if that import actually ran.

## 🛠️ Technologies Used

* **Frontend:** HTML5, JavaScript (Vanilla), TailwindCSS (CDN), Lucide Icons.
* **Backend (Cloudflare Workers):** Dynamic export API for generating Bash scripts and JSON metadata.
* **JS Libraries:** JSZip, FileSaver.js.
